# Архив Фазбера

Статическая хронология и справочник по первым четырём играм Five Nights at Freddy’s. Нет сборки и пакетных зависимостей: GitHub Pages отдаёт файлы прямо из корня репозитория.

## Публикация на GitHub Pages

1. Загрузите репозиторий на GitHub.
2. Откройте **Settings → Pages** и выберите **GitHub Actions** в разделе Build and deployment.
3. Отправьте изменения в ветку `main` или запустите workflow **Deploy to GitHub Pages** вручную во вкладке Actions.

Workflow публикует `index.html`, `glossary.html`, `styles.css` и `app.js` из корня репозитория. Для локального просмотра достаточно открыть `index.html` в браузере.

## Содержание

- Длинная горизонтальная хронология с отдельной карточкой для каждого события и фильтрами по играм и книжным источникам.
- Страница справочника терминов с переходами из карточек хронологии.
- В данных событиям назначаются отдельные `continuity` и `branch`, чтобы добавлять другие версии хронологии.

Год 1993 для FNaF 1 — распространённая реконструкция, а не дата, напечатанная в игре. Для FNaF 3 игра сообщает интервал в 30 лет после закрытия пиццерии. Книжные события отделены от игрового канона переключателем.
