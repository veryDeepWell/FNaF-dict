# Архив Фазбера

Небольшой статический интерактивный справочник по первым четырём играм Five Nights at Freddy’s. Нет сборки и внешних зависимостей: GitHub Pages отдаёт файлы прямо из корня репозитория.

## Публикация на GitHub Pages

1. Загрузите репозиторий на GitHub.
2. Откройте **Settings → Pages** и выберите **GitHub Actions** в разделе Build and deployment.
3. Отправьте изменения в ветку `main` или запустите workflow **Deploy to GitHub Pages** вручную во вкладке Actions.

Workflow публикует `index.html`, `styles.css` и `app.js` из корня репозитория. Для локального просмотра достаточно открыть `index.html` в браузере.

## Содержание

- Горизонтальная хронология с фильтрами по играм и книжным источникам.
- Карточки событий с заметками об источниках и степени уверенности.
- Справочник терминов с переходами из карточек.
- В данных событиям назначаются отдельные `continuity` и `branch`, чтобы добавлять другие версии хронологии.

Год 1993 для FNaF 1 — распространённая реконструкция, а не дата, напечатанная в игре. Для FNaF 3 игра сообщает интервал в 30 лет после закрытия пиццерии. Книжные события отделены от игрового канона переключателем.
